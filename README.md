# 👻 GHOST PARTY

*A spooky game developed for the [Setfire Halloween Jam](https://itch.io/jam/setfire-halloween-jam).*

## 🎮 About the Game

**Ghost Party** is a supernatural game set in a haunted mansion.

You play as a mischievous ghost whose mission is to scare all the guests and make them flee the mansion. Use paranormal abilities, interact with your surroundings, and avoid the owner's watchful eye.

Can you turn the mansion into a place of pure terror without getting caught?

## 🎯 Objective

**Scare all the guests out of the mansion without losing all your lives.**

## 🕹️ Controls

| Key | Action |
|---|---|
| ZQSD / WASD / Arrow Keys | Move |
| `SPACE` | Poltergeist |
| `SHIFT` | Flicker |
| `E` | Apparition |

## 👻 Abilities

### Poltergeist — `SPACE`
Manipulate nearby objects and throw them to frighten guests.

### Flicker — `SHIFT`
Make nearby lights flicker to create fear and confusion.

### Apparition — `E`
Reveal your ghostly presence and frighten nearby guests.

## ❤️ Lives

You start the game with **3 lives**.

When caught by the owner:
- You lose one life.
- You are sent back to your starting point.
- You can continue as long as you have lives remaining.

Losing all your lives results in a **Game Over**.

## ⚡ Energy

Using supernatural abilities consumes energy.

Energy regenerates automatically over time. Manage it carefully to make the most of your powers.

## 🛠️ Built With

- **Unity 6.5** — Game Engine (`6000.5.5f1`)
- **C#** — Gameplay programming

## 🚀 Getting Started

### Requirements
- Unity Hub
- Unity **6000.5.5f1** (Unity 6.5)

### Installation
1. Clone or download this repository.
2. Open Unity Hub.
3. Add the project folder to Unity Hub.
4. Open it using the specified Unity version.
5. Open the `MainMenu` scene.
6. Press **Play** to start the game.
